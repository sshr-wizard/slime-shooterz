# 🎮 SLIME SHOOTERZ

### *Aliens are friends, we just don't understand them yet...*

---

## 📖 About The Game

**Slime Shooterz** is an action-packed space shooter with a twist! You play as **MANBOY**, a brave space pilot defending Earth from the misunderstood Slime Aliens. They destroyed our satellites and blotted out the sun - but are they really the enemy? 

Fight through waves of alien ships, collect powerful upgrades, and face off against massive boss aliens in this thrilling arcade adventure!

**"They came from the void... Green. Slimy. Hungry."**

---

## ✨ Features

### 🎯 Gameplay
- **Mouse Aim & Shoot** - Click to fire at enemies
- **Keyboard Movement** - Arrow keys or WASD to move
- **3 Unique Boss Types** - Slime King, Alien Queen, Cosmic Slime
- **Multiple Boss Waves** - Bosses spawn every 500 points
- **Power-up System** - Collect glowing orbs for temporary boosts
- **Bullet Blocking** - Your bullets can destroy enemy projectiles
- **Explosion Effects** - Satisfying visual explosions with PNG sprites

### ⚡ Power-ups
- **⚡ Rapid Fire** - Shoot faster bullets (1.5x speed)
- **✨ Spread Shot** - Fire 3 bullets at once
- **🛡️ Shield** - Protect from damage + double damage bullets

### 🎬 Visual & Audio
- **Logo Splash Screen** - Game logo with fade effects
- **Movie-Style Story Loading** - Horror-themed narrative intro
- **Background Music** - Suspenseful atmospheric music
- **Sound Effects** - Gun shots, explosions, warnings
- **Parallax Stars** - Twinkling starfield background
- **Particle Explosions** - Glowing particle effects

### 🎮 Controls
| Action | Key/Button |
|--------|------------|
| Move Up | ↑ or W |
| Move Down | ↓ or S |
| Move Left | ← or A |
| Move Right | → or D |
| Shoot | Left Mouse Click or SPACE |
| Pause/Resume | ESC |
| Restart | R (when game over) |

## 📦 Installation

### Option 1: Play the EXE (Recommended for Non-Programmers)
1. Download `SlimeShooterz.exe` from the `dist` folder
2. Double-click to play (No Python installation needed!)

### Option 2: Run from Source (For Developers)
```bash
# Clone or download the project
cd slime_shooterz

# Install dependencies
pip install -r requirements.txt

# Run the game
python main.py
