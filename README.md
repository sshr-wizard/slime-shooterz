# Space Shooter Game - Pygame Version

A classic space shooting game built with Pygame that works on older hardware.

## Features

- Player ship with smooth movement (Arrow Keys / WASD)
- Easy enemies with wobble movement
- Boss enemy that appears at 50 points
- Boss health bar and warning system
- Boss shoots homing bullets
- Sound effects support
- Beautiful starfield background with twinkling
- Score and lives system
- Game over and restart functionality
- Works on older graphics hardware

## Requirements

- Python 3.7+
- Pygame 2.5.0+
